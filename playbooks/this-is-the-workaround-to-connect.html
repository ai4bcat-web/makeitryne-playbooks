A Make It Ryne Playbook

The One Link That Wires Claude Into 8,000 Apps

Paste a single URL into Claude and it can draft your Gmail replies, log deals in your CRM, and ping your Slack. No workflow builder. No code. Set up in about ten minutes.

Time: ~10 min Cost: free to start Skill: zero code

What you'll build

Claude is smart, but out of the box it can't touch your inbox, your spreadsheets, or your CRM. The bridge that fixes that is called MCP, the Model Context Protocol. It's an open standard for how AI models talk to outside tools. Zapier runs an MCP server that exposes its entire catalog, roughly 8,000 apps and 30,000 actions, through one URL.

By the end of this playbook you'll have:

  • A Zapier MCP server with your apps connected (Gmail, Slack, Google Sheets, or whatever you use)
  • That server wired into Claude as a custom connector
  • A working "new lead" workflow you trigger with one plain-English sentence: reply drafted, deal logged, team notified
Before you start: custom connectors require a paid Claude plan (Pro, Max, Team, or Enterprise). Zapier MCP has a free tier that's plenty for testing.
1

Create your Zapier MCP server

This is where your one link comes from.

Do this:

Go to mcp.zapier.com and sign in with your Zapier account (create a free one if needed). Click New MCP Server. When it asks which client you're connecting, choose Claude. Give the server a name you'll recognize, something like claude-ops.

Zapier generates a unique server URL. That URL is a credential. Anyone who has it can fire your connected actions, so treat it like a password. Don't screenshot it, don't paste it in a group chat, and if it ever leaks, rotate it from the same dashboard.

2

Add the actions Claude is allowed to use

An empty server does nothing. You have to explicitly grant tools. This is a feature, not a chore: Claude can only ever do what you've approved here.

Do this:

Inside your new server, click Add tool (Zapier sometimes labels these "actions"). For the lead workflow in this playbook, add these three:

  • Gmail: Create Draft. Drafts, not sends. You keep the final click.
  • Google Sheets: Create Spreadsheet Row. Point it at a sheet with columns like Name, Email, Source, Status, Date.
  • Slack: Send Channel Message. Pick the channel where your team watches leads.

Each tool asks you to authenticate the underlying account the first time. That's normal OAuth, same as connecting any Zap. For fields, leave most of them set to "Have AI guess a value" so Claude can fill them from context, but hard-code anything that should never change, like the Slack channel name.

Start narrow. Three tools beats thirty. Every tool you add is something the model can invoke, so grant read and draft actions first, and add send or delete powers only after you trust the behavior.
3

Paste the link into Claude

This is the sixty-second part from the video.

Do this:

Open Claude in your browser at claude.ai. Then:

  • Click your initials, then Settings
  • Open Connectors
  • Scroll down and hit Add custom connector
  • Name it (mine is just "Zapier"), paste your MCP server URL, and click Add
  • Click Connect on the new row and approve the Zapier authorization screen

When the row shows as connected, that one link just handed Claude every action you granted in Step 2. Open a new chat, click the tools icon (the sliders) near the input box, and confirm your Zapier connector is toggled on with your three tools listed.

On Team or Enterprise? An admin may need to enable custom connectors for the workspace first, under organization settings.
4

Run the lead workflow with one sentence

No workflow builder. No trigger diagrams. You just describe the outcome and Claude picks the tools itself.

Do this:

Start a new chat and paste a real inbound lead (forwarded email text works fine), then a prompt like this:

# Prompt: the one-sentence ops run
Here's a new lead that just emailed me: [paste the email]

Do three things:
1. Draft a warm, short Gmail reply that answers their
   question and proposes a 15-minute call this week.
2. Add them to my Leads sheet with today's date and
   Status set to "New".
3. Post a one-line summary to the #leads Slack channel
   with their name and what they asked for.

Claude will ask permission the first time it calls each tool. Approve them, watch each one tick to done, then verify: the draft is sitting in Gmail, the row is in your sheet, the ping landed in Slack. In my runs the whole chain finishes in under a minute.

If a tool call fails:

Nine times out of ten it's one of these. Check them in order:

  • Tool not granted. The action isn't added on the Zapier MCP dashboard. Add it, then retry in a fresh chat.
  • Auth expired. Reconnect the app account inside Zapier.
  • Ambiguous target. Claude guessed the wrong sheet or channel. Hard-code that field in the Zapier tool config instead of letting AI guess it.
5

Turn it into a reusable playbook

Typing the same three-part prompt every time defeats the point. Save it once.

Do this:

Create a Claude Project called "Lead Ops" and drop your workflow rules into the project instructions:

# Project instructions: Lead Ops
When I paste an inbound lead email, always:
- Draft a reply in Gmail. Never send, only draft.
- Log the lead in the "Leads" Google Sheet.
- Post a summary to #leads in Slack.
Tone for drafts: friendly, direct, two short paragraphs max.
Always confirm what you did in a bullet list at the end.

Now the entire workflow is: open the project, paste the email, hit enter. From here, expand sideways. Add a CRM tool for deal stages, a Calendar tool for booking the call, or a Notion tool for meeting notes. Same one link, more granted actions.

Recap checklist

  • Created an MCP server at mcp.zapier.com with Claude as the client
  • Granted exactly the tools I need: Gmail draft, Sheets row, Slack message
  • Kept the server URL private, ready to rotate if it leaks
  • Added the URL in Claude under Settings, Connectors, Add custom connector
  • Verified the tools show up in a new chat
  • Ran the one-sentence lead workflow and checked all three outputs
  • Saved the workflow as project instructions so it's one paste from now on

The apps were never the hard part. The bridge was. Now you have it.
